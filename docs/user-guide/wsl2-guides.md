# Loss Prevention on WSL2

To run Loss Prevention on Windows 11, you need to have WSL2 installed and set up.
Follow these guides to install and configure WSL2:

- [Set Up Loss Prevention on WSL2](./wsl2/wsl2-setup.md): set up WSL2 on a clean Windows 11 machine.
- [WSL Benchmark Hardware Metrics](./wsl2/wsl-hardware-metrics.md): set up hardware metrics for WSL benchmarks.
- [Benchmark Metrics on WSL2](./wsl2/wsl2-benchmark.md): run benchmarks on WSL2.
